Marktone

A desktop Markdown editor for macOS and Linux that shows your document rendered as you write it, and saves it as plain Markdown.

Version 0.56.3

New since 0.54.1

  • Find window controls around the document. The top row holds File, zoom, Read or Edit, and the panel toggles. The bottom row holds About, Help, theme, version, Update and Settings. The folder sidebar opens independently in folder windows, and both side panels match the document in Day and Night. The moon and sun show the appearance you will switch to.
  • Find file commands and shortcuts more easily. The File popover offers Open File, Open Folder, Save, Save As, Export as HTML and Export as PDF. Control tips show their shortcuts where available and stay clear of panel titles and notices. The About popover shows the running version alongside marktone.app and whl.ltd.
  • Check for updates with one click. The Update icon downloads and verifies a newer package. The version label changes when the package is ready to install. An up-to-date result or a failed check or download shows a notice for four seconds.
  • Fine-tune document font weight in Settings. The variable-font slider lets you choose intermediate weights. Bold and italic text stay rendered while Settings has focus.
  • Fill and restore a Mac window from its title bar. Double-click the blank title area to use the action set in macOS.
  • Keep working through temporary picture download failures. Marktone retries twice in the background when opening, typing or pasting a remote picture. If the retries run out, it keeps the original address or pasted text and explains the failure. Local picture paths you write by hand are preserved.

macOS (Apple silicon)

↓ Marktone-arm64.dmg 19.3 MB · SHA-256

Open the .dmg and drag Marktone into Applications. The first time, right-click Marktone in Applications and choose Open: Marktone is not notarised by Apple, so macOS refuses a plain double-click.

Linux (x86-64)

Install Marktone, or update it, with one line in a terminal. It puts Marktone, its menu entry and its icon in your own folders under ~/.local, and needs no sudo:

curl -fsSL https://marktone.app/install.sh | sh

Remove it with this line. It removes only what the installer put in place, and keeps your settings and your Markdown files:

curl -fsSL https://marktone.app/uninstall.sh | sh

Or download a package:

↓ Marktone-x86_64.AppImage 26.2 MB · SHA-256
Make it executable with chmod +x Marktone-x86_64.AppImage, then run it.

↓ Marktone-amd64.deb 27.7 MB · SHA-256
On Debian or Ubuntu: sudo apt install ./Marktone-amd64.deb

↓ Marktone-x86_64.tar.gz 27.7 MB · SHA-256
Unpack it and run marktone in the unpacked folder; its desktop file and icon are beside it.
