Marktone

A desktop Markdown editor for macOS and Linux that shows your document rendered as you write it, and saves it as plain Markdown.

Download

Version 0.54.1

New since 0.52.8

  • Install Linux updates from Settings. Once you have 0.54.1, choose Check for Updates, then Install and Restart when an update is offered. This works with AppImage, Debian and portable tar installations. Download 0.54.1 from the website to upgrade from 0.52.8.
  • Choose Ioskeley Mono in Settings. The font is bundled, so you can try it without a separate installation. Your existing font choice is preserved.
  • Write punctuation exactly as you want it to appear. Type \*literal\* to display *literal* in your document and its outline. Copying and saving preserve the Markdown escapes, and code keeps its literal backslashes.
  • Work more smoothly in long documents. Long tables need less work to draw as you scroll, and editing ordinary text in a nested list does not reparse the whole list. On macOS, font discovery runs alongside startup work to reduce the wait before a folder window opens.
  • Read footnote markers more easily. Badges reserve space in the line, so they stay clear of adjacent text when a line wraps.
  • Recover from a save error with Save As. Once your document saves to the new location, the earlier error message clears.

macOS (Apple silicon)

↓ Marktone-arm64.dmg 19.3 MB · SHA-256

Open the .dmg and drag Marktone into Applications. The first time, right-click Marktone in Applications and choose Open: Marktone is not notarised by Apple, so macOS refuses a plain double-click.

Linux (x86-64)

Install Marktone, or update it, with one line in a terminal. It puts Marktone, its menu entry and its icon in your own folders under ~/.local, and needs no sudo:

curl -fsSL https://marktone.app/install.sh | sh

Remove it with this line. It removes only what the installer put in place, and keeps your settings and your Markdown files:

curl -fsSL https://marktone.app/uninstall.sh | sh

Or download a package:

↓ Marktone-x86_64.AppImage 25.5 MB · SHA-256
Make it executable with chmod +x Marktone-x86_64.AppImage, then run it.

↓ Marktone-amd64.deb 27.2 MB · SHA-256
On Debian or Ubuntu: sudo apt install ./Marktone-amd64.deb

↓ Marktone-x86_64.tar.gz 27.2 MB · SHA-256
Unpack it and run marktone in the unpacked folder; its desktop file and icon are beside it.
