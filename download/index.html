macOS (Apple silicon)

Download for macOS

SHA-256 checksum: Marktone-arm64.dmg.sha256

  1. Open the downloaded .dmg.
  2. Drag Marktone into Applications.
  3. The first time you open it, right-click Marktone in Applications, choose Open, and confirm. Marktone is not notarised by Apple, so macOS refuses a plain double-click the first time.

Linux (x86-64)

Download the AppImage

Or the Debian and Ubuntu package, or the .tar.gz archive.

SHA-256 checksums: AppImage · package · archive

  • AppImage: make it executable with chmod +x Marktone-x86_64.AppImage, then run it.
  • Debian or Ubuntu: sudo apt install ./Marktone-amd64.deb
  • Archive: unpack it and run marktone in the unpacked folder; its desktop file and icon are beside it.
