Marktone

A desktop Markdown editor for macOS and Linux that shows your document rendered as you write it, and saves it as plain Markdown.

Download

Version 0.80.0

New in Export as PDF

  • Marktone now makes the PDF itself. Export as PDF no longer needs a browser or any other program installed: Marktone writes the PDF on its own, so it works on every Mac and Linux machine, and the old prompt offering HTML when no browser was found is gone.
  • Pages as the window draws them. The PDF is A4 with 2.6 cm margins on all four sides, its body at 9 pt with headings, spacing and pictures in proportion, in the day theme's look and the font chosen in Settings. Code blocks, quotes, rules, tables, task boxes, footnotes, colour emoji and pictures are drawn as in the window, and a code block's long lines wrap so nothing is cut off.
  • Wide content turns the page. When a table cannot fit the page without breaking a word, or a code line is too long for it, the whole PDF is set in A4 landscape. Pictures never turn a page: they are made smaller to fit.
  • Easy to read across pages. Each page carries its number, small and centred at its foot. A table that runs on to another page repeats its header row there, and a heading is never left alone at a page's foot.
  • A PDF you can use. Its bookmarks are the document's headings. Links open, links to a heading jump to it, and footnotes jump to their text and back. Text can be selected, copied and searched, Chinese included, and local pictures are held inside the file.
  • Safe to export over an old copy. A failed export leaves no half-written file and keeps the PDF it would have replaced; one that succeeds keeps the old file's permissions.

New in the window and its panels

  • The window grows to show a panel. Opening the sidebar, the outline or Settings in a window too narrow for it grows the window by what the panel lacks, so the text stays where it is on the screen. On the Mac it grows towards the panel's side; on Linux it grows to its right, and the text moves only as far as the sidebar needs. Closing the panel keeps the new width. A full-screen, maximised or tiled window does not grow and keeps its rules as before.
  • Read or Edit comes before Theme in the group of icons at the top of the window.

New in tables

  • Column edges stay still while you edit. While the caret is in a table, typing in a cell, or a cell showing its Markdown, changes only that cell's wrapping and its row's height, never where the columns meet. The columns are shared out again when the caret leaves the table, or at once when a row or column is added or removed.

New in Find and replace

  • Undo works in the Find bar. With the caret in the find or the replace field, Cmd+Z (Ctrl+Z on Linux) undoes the field's typing first, then the document's edits once the field has nothing left to undo; Shift+Cmd+Z (Ctrl+Y) redoes them in the same order. The Edit menu's Undo and Redo follow the same route.

New in the app

  • A new icon: Marktone's woven # mark, rounded by macOS as every Mac icon is, and drawn with the same rounded corners for Linux desktops.
  • Third-party licences in one file. Every package carries licences/THIRD-PARTY-LICENCES.md, listing the licence of every component Marktone is built from.

macOS (Apple silicon)

↓ Marktone-arm64.dmg 18.4 MB · SHA-256

Open the .dmg and drag Marktone into Applications. The first time, right-click Marktone in Applications and choose Open: Marktone is not notarised by Apple, so macOS refuses a plain double-click.

Linux (x86-64)

Install Marktone, or update it, with one line in a terminal. It puts Marktone, its menu entry and its icon in your own folders under ~/.local, and needs no sudo:

curl -fsSL https://marktone.app/install.sh | sh

Remove it with this line. It removes only what the installer put in place, and keeps your settings and your Markdown files:

curl -fsSL https://marktone.app/uninstall.sh | sh

Or download a package:

↓ Marktone-x86_64.AppImage 23.9 MB · SHA-256
For a portable copy, make it executable with chmod +x Marktone-x86_64.AppImage, then run it. To install the AppImage with a menu entry and Markdown file associations, use curl -fsSL https://marktone.app/install.sh | sh -s -- --appimage.

↓ Marktone-amd64.deb 25.2 MB · SHA-256
On Debian or Ubuntu: sudo apt install ./Marktone-amd64.deb

↓ Marktone-x86_64.tar.gz 25.2 MB · SHA-256
Unpack it and run marktone in the unpacked folder; its desktop file and icon are beside it.
