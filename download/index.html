Marktone

A desktop Markdown editor for macOS and Linux that shows your document rendered as you write it, and saves it as plain Markdown.

Download

Version 0.89.3

New in the interface's language

  • The interface follows the system. Marktone now opens in the first of the system's languages that it is written in: English, Simplified Chinese, Traditional Chinese or Japanese. Until now the interface stayed in British English.
  • A Language choice in Settings. Settings now have Language, first under Interface: Follow System, then each language in its own script. Every word of the interface follows the choice at once, in every window. Help follows that language until you pick a language in Help itself.

New in Editing

  • Enter at the start of a quote. Pressing Enter at the start of a quotation's first line now moves the quote down one line, as it does for a paragraph. Empty lines before the quote are drawn and can take the caret.
  • Enter on an empty line above a block. Pressing Enter on an empty line above a block, where the caret does not rest at the start, now takes the caret and the block below down one line. Backspace still takes back the empty lines above a block, but leaves a line that already holds the writer's spaces.

New in Chinese

  • 界面 in both written forms. The word for the interface is now 界面 in both Simplified and Traditional Chinese, including Settings and Help. Traditional Chinese had used 介面, so the two variants no longer use different words for the same thing.

macOS (Apple silicon)

↓ Marktone-arm64.dmg 18.6 MB · SHA-256

Open the .dmg and drag Marktone into Applications. The first time, right-click Marktone in Applications and choose Open: Marktone is not notarised by Apple, so macOS refuses a plain double-click.

Linux (x86-64)

Install Marktone, or update it, with one line in a terminal. It puts Marktone, its menu entry and its icon in your own folders under ~/.local, and needs no sudo:

curl -fsSL https://marktone.app/install.sh | sh

Remove it with this line. It removes only what the installer put in place, and keeps your settings and your Markdown files:

curl -fsSL https://marktone.app/uninstall.sh | sh

Or download a package:

↓ Marktone-x86_64.AppImage 23.7 MB · SHA-256
For a portable copy, make it executable with chmod +x Marktone-x86_64.AppImage, then run it. To install the AppImage with a menu entry and Markdown file associations, use curl -fsSL https://marktone.app/install.sh | sh -s -- --appimage.

↓ Marktone-x86_64.tar.gz 25.0 MB · SHA-256
Unpack it and run marktone in the unpacked folder; its desktop file and icon are beside it.
