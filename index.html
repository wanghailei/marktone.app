Marktone

A desktop Markdown editor for macOS and Linux that shows your document rendered as you write it, and saves it as plain Markdown.

Download

Version 0.85.4

New in writing

  • Empty lines in lists and quotes keep their space. An empty line inside a list item or a quote is now drawn as an empty paragraph of that item or quote, so nothing below it moves when the caret arrives on it or leaves it.
  • Blank lines between list items are lines you can write on. The caret rests on each of them, Up and Down stop there, and you can type there. Backspace, Delete and Enter on such a line take away or add one line.
  • Text typed on an empty line in a list item stays in that item. It no longer leaves the list and cuts the item in two; in a quote it stays in the quote.
  • An emptied paragraph keeps its line. When you delete all the text of a paragraph that stands between two headings or other blocks, its line stays as an empty paragraph, and the text below no longer jumps up.
  • Spaces at the start of a line are shown as typed. A paragraph's leading spaces and tabs are drawn where you typed them, in Edit and in Read, and the caret stays after them. HTML and PDF exports show them as the window does.
  • Four spaces never make a code block. A line that starts with four or more spaces, or with a tab, stays the text it was; code blocks come only from fences. A file written elsewhere with an indented code block opens as indented text.

New in Help

  • Choose Help's language. A language icon at the top of Help's window lists English, 简体中文, 繁體中文 and 日本語. Pick one and Help is redrawn in it at once, and opens in it from then on; pick the row marked System to follow your system again.
  • Skeletons in Help's language. Insert Skeleton writes the placeholder words of its skeletons, such as Title, Section and Item, in the language Help is shown in. The Markdown marks stay the same.

New in the Linux packages

  • The Linux packages now need Ubuntu 24.04 or newer (glibc 2.39); 0.83.8's were built for Ubuntu 22.04.
  • They run on Ubuntu 24.04 and 26.04, Debian 13, Arch and Omarchy, and not on older systems such as Ubuntu 22.04 or Debian 12.

Open the .dmg and drag Marktone into Applications. The first time, right-click Marktone in Applications and choose Open: Marktone is not notarised by Apple, so macOS refuses a plain double-click.

Linux (x86-64)

Install Marktone, or update it, with one line in a terminal. It puts Marktone, its menu entry and its icon in your own folders under ~/.local, and needs no sudo:

curl -fsSL https://marktone.app/install.sh | sh

Remove it with this line. It removes only what the installer put in place, and keeps your settings and your Markdown files:

curl -fsSL https://marktone.app/uninstall.sh | sh

Or download a package:

The Problem

Plain Markdown is easy to keep and hard to read: every heading, emphasis and table is wrapped in #, ** and |. A separate preview pane means reading in one place and writing in another.

What Marktone Does

Shows the document, not the markup. Headings, emphasis, lists, quotes, tables, code, links, pictures, task lists and footnotes are drawn as they read. The block under the caret shows its Markdown, so you always edit the real text.

Saves as you go, and changes only what you edited. Every change is saved to the file without asking. Files with Windows line endings are saved with Unix line endings. If another program changes the file you are editing, Marktone tells you.

Reads comfortably, day and night. A day theme and a night theme follow your system's light or dark setting. Settings sets the font (Berkeley Mono Variable when installed), its size and weight, the line height and the width of the text column.

Works across a folder. Open Folder lists a folder's Markdown files in a sidebar, and the outline lists the document's headings, taking you to one with a click. Find and Replace work across the document, Chinese included.

Helps you write. Brackets, quotes and ** close as you type, copying gives Markdown, and a task's checkbox ticks with a click. A pasted picture is saved in a <document name>.assets folder beside the document and linked.

Exports to HTML and PDF. Export as HTML writes an HTML file. Export as PDF prints A4 pages through an installed Chrome, Chromium, Edge or Brave.

Marktone has no plugins, maths, diagrams, custom CSS or account.

When to Use Marktone

Keeping notes, drafts or a book in Markdown files, and wanting to read them rendered while you write.

Editing READMEs and documentation that must stay plain Markdown in the repository.

Writing in Chinese and English, with the system's input methods.
